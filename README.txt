JAGADEESH AGRICULTURE - B.TECH 3RD YEAR PROJECT

Pages:
1. index.html - Home with automatic image slider
2. about.html - About + CEO profile
3. crops.html - Crop information
4. techniques.html - Modern farming techniques
5. fertilizers.html - Searchable fertilizer store + demo cart
6. farmer.html - Farmer registration form
7. gallery.html - Agriculture gallery
8. contact.html - Contact form

Folders:
css/style.css
js/script.js
images/

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Use the navigation menu to open all pages.

NOTE:
The fertilizer shopping and forms are frontend academic-project demonstrations only.
The local image files are lightweight offline agriculture artwork so the ZIP works without internet.
For final submission, you can replace them with the selected free-to-use photos from Pexels/Unsplash while keeping the same filenames.
Your uploaded CEO photo is included as images/ceo.jpg.
